Memories of Love

Mete aquí las imágenes del proyecto siguiendo esta estructura:

portada.jpg  -> imagen que aparecerá en la tarjeta del portfolio
01.jpg       -> primera imagen del carrusel
02.jpg       -> segunda imagen
03.jpg       -> tercera imagen
...

Puedes añadir hasta 20 imágenes numeradas (01.jpg a 20.jpg).
No necesitas modificar ningún código.

Para vídeos, por ahora usa también portada.jpg como miniatura. El vídeo/enlace se puede añadir después.
