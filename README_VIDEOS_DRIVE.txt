PORTFOLIO V14 — VIDEOS EXTERNOS Y ZOOM DE IMÁGENES

Vídeos:
- Puedes seguir usando vídeos locales cortos en cualquier proyecto:
  "videos": ["video.mp4"]
- También puedes usar vídeos externos:
  "videos": [
    {
      "name": "Nombre del vídeo",
      "url": "https://drive.google.com/..."
    }
  ]

Las dos modalidades pueden convivir en el mismo gallery.json.

Google Drive:
1. Sube el vídeo a Drive.
2. Compartir -> Acceso general -> Cualquier persona con el enlace -> Lector.
3. Copia el enlace y colócalo en "url".

Imágenes:
- Al hacer clic en cualquier imagen del carrusel, se abre en una vista ampliada.
- Escape o el botón X cierra la vista ampliada.
